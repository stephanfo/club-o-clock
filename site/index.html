Le planning d'entraînement de ton club.

Sans le tableur partagé ni le fil de discussion interminable. Les adhérents voient les séances et s'inscrivent depuis leur téléphone ; les coachs savent qui vient ; les places limitées se gèrent toutes seules, liste d'attente comprise.

Ce qui le distingue

Un logiciel qui appartient au club

Pas un service auquel on s'abonne : une application que le club installe, possède et personnalise.

Tes données restent chez toi

Une instance par club, sur ton hébergement. Pas de SaaS, pas d'abonnement, pas de tiers qui exploite le fichier de tes adhérents.

RGPD par construction

Ni numéro de téléphone, ni certificat médical, ni numéro de licence. Aucun service non européen dans le chemin critique, polices auto-hébergées, aucun traqueur.

Ça tourne sur un mutualisé

Un hébergement mutualisé avec accès SSH suffit, entre 50 et 150 € par an. Ni Docker, ni serveur Node, ni WebSocket : du PHP et une tâche planifiée.

C'est le club de l'utilisateur

Nom, logo, baseline et palette de couleurs se règlent depuis l'administration. Pas besoin de toucher au code.

Installable comme une app

Sur l'écran d'accueil du téléphone, sans passer par un store. Notifications push comprises.

Libre, sous AGPL-3.0

Utilisable, modifiable, et qui le reste. Quiconque déploie une version modifiée doit en publier le code — c'est ce que garantit l'AGPL.

Pour le bureau

Ce que le président et le trésorier vont demander

Les réponses sans jargon, à transmettre telles quelles.

Combien ça coûte ?

Le logiciel est gratuit. Le club paie seulement son hébergement, chez l'hébergeur de son choix.

Coût annuel pour le club
Logiciel0 €
Hébergement web avec accès SSH50 à 150 €
Nom de domaine si le club n'en a pas~10 €
Envoi des emails offre gratuite de Brevo0 €
Total par an50 à 160 €

Hébergeur testé : OVH, offre Pro — dans le haut de la fourchette une fois la promotion de première année passée.

Qui l'installe, et en combien de temps ?

Une personne à l'aise avec l'informatique et la ligne de commande — un bénévole, un parent d'adhérent. Compter une demi-journée.

Seul vrai prérequis : l'hébergement doit offrir un accès SSH (des commandes tapées à distance). Les offres d'entrée de gamme n'en ont pas : chez OVH, il faut l'offre Pro.

Ensuite, le bureau paramètre le club depuis l'interface, sans compétence technique. Personne sous la main ? L'auteur peut aider à l'installation, sur demande.

Et les mises à jour ?

Quelques nouvelles versions par an. Chacune prend une trentaine de minutes à la personne qui a fait l'installation.

Le club choisit quand les appliquer : sans mise à jour, l'application continue de fonctionner. Seules les corrections de sécurité sont à installer sans attendre.

Et si l'auteur arrête ?

L'application continue de tourner : elle est installée chez le club, pas chez l'auteur, et les données restent les siennes.

Le code est public et libre (licence AGPL) : n'importe quel développeur peut le reprendre, le corriger, le faire évoluer. Ce qui s'arrêterait, ce sont les nouvelles versions de l'auteur. C'est un projet bénévole, sans engagement de durée.

Peut-on récupérer nos données ?

Oui, elles sont sur l'hébergement du club. Les statistiques et les journaux s'exportent en Excel depuis l'administration.

Le reste — adhérents, séances, inscriptions — se récupère avec l'outil de base de données de l'hébergeur, en CSV lisible dans Excel.

Et le RGPD ?

Ni téléphone, ni certificat médical, ni numéro de licence, aucun traqueur : l'application ne garde que le nécessaire.

Le kit RGPD fournit, prêts à compléter, le texte d'information des adhérents et la fiche pour le registre des traitements du club.

Écrire à l'auteur
Installer

Une demi-journée, et le club a son instance

Il faut un hébergement avec accès SSH — chez OVH, l'offre Pro ; les offres d'entrée de gamme n'en ont pas — et une personne à l'aise avec la ligne de commande. Il n'y a pas d'inscription publique : le premier administrateur se crée en ligne de commande, et c'est lui qui invite le reste du club.

Déposer le code

Sur un hébergement mutualisé PHP 8.3 avec MySQL ou MariaDB et accès SSH. L'interface se compile sur son ordinateur, puis tout part par SFTP.

Configurer

Le fichier .env, la base de données, l'envoi d'email, et une tâche planifiée — c'est elle qui cadence les notifications et la météo.

Créer le premier compte

Une commande en SSH, et le bureau prend la main sur le reste depuis l'interface.

# sur ton ordinateur
$ git clone https://github.com/stephanfo/club-o-clock.git
$ npm ci && npm run build # l'interface, à envoyer avec le code par SFTP
# sur l'hébergement, en SSH, une fois le .env rempli
$ composer install --no-dev --optimize-autoloader
$ php artisan key:generate
$ php artisan migrate --force
$ php artisan db:seed --force # catalogues — indispensable, même en production
$ php artisan club:create-admin # le seul point d'entrée d'une base vide
# puis la checklist du guide : lien du logo, caches, tâche planifiée

Questions fréquentes

Ce que demandent les clubs avant de se lancer

Combien ça coûte ?

Rien pour le logiciel : il est libre, sous licence AGPL, sans abonnement ni coût par adhérent. Le club paie son hébergement, entre 50 et 150 € par an selon l'hébergeur — il doit offrir un accès SSH ; OVH Pro est l'offre de référence testée —, plus son nom de domaine s'il n'en a pas. L'envoi des emails, indispensable, reste gratuit avec l'offre gratuite de Brevo.

Pour quels sports ?

Il est né dans un club de triathlon (natation, vélo, course à pied), mais les disciplines, catégories d'âge et types d'épreuve sont des catalogues que le club paramètre. Tout club qui propose des séances d'entraînement avec inscription peut s'en servir.

Faut-il un informaticien ?

Pour l'installation, oui : une personne à l'aise avec la ligne de commande, car l'hébergement doit offrir un accès SSH et plusieurs étapes s'y font. Compter une demi-journée ; l'auteur peut aider, sur demande. Ensuite, tout se gère depuis l'interface : séances, adhérents, rôles, paramètres du club. Seules les mises à jour, quelques fois par an, redemandent une trentaine de minutes à cette personne.

Les adhérents doivent-ils installer une application ?

Non : elle s'ouvre dans le navigateur du téléphone, sans passer par un store. Chacun peut l'ajouter à son écran d'accueil pour l'utiliser comme une application, notifications comprises.

Pour quelle taille de club ?

Elle est pensée pour un club associatif de 50 à 150 adhérents, administré par des bénévoles. Les mineurs sont gérés par leurs parents, puis prennent leur compte en main en grandissant.

Et les données des adhérents ?

Elles restent chez le club, sur son hébergement : aucun tiers n'y a accès. L'application ne stocke ni numéro de téléphone ni certificat médical, et un adhérent peut demander la suppression de son compte. Un kit RGPD fournit le texte d'information des adhérents et la fiche du registre des traitements.
