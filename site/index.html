Nage, pédale, cavale… fini le planning infernal !

Le planning d'entraînement de ton club.

Sans le tableur partagé ni le fil de discussion interminable. Les adhérents voient les séances et s'inscrivent depuis leur téléphone ; les coachs savent qui vient ; les places limitées se gèrent toutes seules, liste d'attente comprise.

Essayer la démo Installer pour mon club

Application installable (PWA) pour club sportif associatif de 50 à 150 adhérents, administré par des bénévoles.

Ce qui le distingue

Un logiciel qui appartient au club

Pas un service auquel on s'abonne : une application que le club installe, possède et personnalise.

Tes données restent chez toi

Une instance par club, sur ton hébergement. Pas de SaaS, pas d'abonnement, pas de tiers qui exploite le fichier de tes adhérents.

RGPD par construction

Ni numéro de téléphone, ni certificat médical, ni numéro de licence. Aucun service non européen dans le chemin critique, polices auto-hébergées, aucun traqueur.

Ça tourne sur un mutualisé

À quelques euros par mois. Ni Docker, ni serveur Node, ni WebSocket : du PHP et un cron.

C'est le club de l'utilisateur

Nom, logo, baseline et palette de couleurs se règlent depuis l'administration. Pas besoin de toucher au code.

Installable comme une app

Sur l'écran d'accueil du téléphone, sans passer par un store. Notifications push comprises.

Libre, sous AGPL-3.0

Utilisable, modifiable, et qui le reste. Quiconque déploie une version modifiée doit en publier le code — c'est ce que garantit l'AGPL.

Essayer sans rien installer

Les identifiants sont affichés sur l'écran de connexion, un clic les remplit. Données entièrement fictives, remises à zéro chaque nuit : n'hésite pas à tout casser.

Ouvrir la démo

Aucun email ni notification ne peut sortir de cette instance — c'est verrouillé côté serveur, pas simplement désactivé. Teste les invitations et les annulations sans crainte.

Installer

Trois étapes, et le club a son instance

Il n'y a pas d'inscription publique : le premier administrateur se crée en ligne de commande, et c'est lui qui invite le reste du club.

Déposer le code

Sur un hébergement mutualisé PHP 8.3 avec MySQL ou MariaDB. Par SFTP, ou par Git si l'hébergeur le propose.

Configurer

Le fichier .env, la base de données, l'envoi d'email, et un cron toutes les cinq minutes.

Créer le premier compte

Une commande, et le bureau prend la main sur le reste depuis l'interface.

$ git clone https://github.com/stephanfo/club-o-clock.git
$ composer install --no-dev && npm ci && npm run build
$ php artisan migrate --force
$ php artisan club:create-admin # le seul point d'entrée d'une base vide
